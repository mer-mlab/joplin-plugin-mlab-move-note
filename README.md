# joplin-plugin-mlab-move-note
Перемещение заметок внутри блокнота при пользовательской сортировке. Перемещение вверх, вниз, в начало, в конец, в середину.
# Перемещение заметок (Move Note) для Joplin

**Версия 2.0.0**

Плагин добавляет в меню текущей заметки (три точки) команды для быстрого перемещения заметки в списке при включённой **пользовательской сортировке** (Custom order). Это особенно удобно на мобильных устройствах, где нет возможности перетаскивать заметки мышкой.

## Возможности

- Перемещение выбранной заметки:
  - **Вверх** – на одну позицию выше.
  - **Вниз** – на одну позицию ниже.
  - **В начало** – в самый верх списка.
  - **В конец** – в самый низ списка.
  - **В середину** – в центр списка.

**Ключевое преимущество:** плагин изменяет порядок, затрагивая **только одну заметку** (её поле `order`), а не все, что значительно ускоряет синхронизацию и снижает нагрузку на сервер, особенно в больших блокнотах.

## Установка

### Через официальный репозиторий Joplin (рекомендуется)

1. Откройте Joplin (версия 3.0 или выше).
2. Перейдите в **Настройки → Плагины**.
3. Нажмите **Установить плагин** и найдите по названию **"Перемещение заметок"** или **"Move Note"**.
4. Установите и перезапустите Joplin.

### Ручная установка (из файла)

1. Скачайте файл `.jpl` из раздела [Releases](https://github.com/mer-mlab/joplin-plugin-mlab-move-note/releases).
2. В Joplin: **Настройки → Плагины → ⋮ (три точки) → Установить из файла**.
3. Выберите скачанный файл и подтвердите установку.
4. Перезапустите Joplin.

## Использование

1. Откройте блокнот, в котором включена **пользовательская сортировка** (нажмите на название блокнота, выберите "Сортировать по" → "Пользовательская").
2. Откройте заметку, которую хотите переместить.
3. Нажмите на **три вертикальные точки** (⋮) в правом верхнем углу экрана (меню заметки).
4. Выберите одно из действий: **Вверх**, **Вниз**, **В начало**, **В конец** или **В середину**.
5. Заметка мгновенно переместится, и список обновится.

> **Примечание:** Команды доступны только при открытой заметке. Если заметка уже находится в крайней позиции (например, самая верхняя), соответствующая команда будет недоступна (появится сообщение).

## Требования

- Joplin версии **3.0** или выше (поддерживаются как десктопные, так и мобильные версии).
- Для мобильных устройств также требуется версия **3.0+**.

## Локализация

Плагин автоматически определяет язык интерфейса Joplin:

- Если язык **русский**, все надписи и сообщения будут на русском.
- Для всех остальных языков используется **английский**.

## Сборка из исходников (для разработчиков)

Если вы хотите собрать плагин самостоятельно:

```bash
git clone https://github.com/ваш-репозиторий/joplin-plugin-move-note.git
cd joplin-plugin-move-note
npm install
npm run dist
```

Готовый файл `.jpl` появится в папке `publish/`.
